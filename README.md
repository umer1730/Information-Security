# Information Security 

This repository contains my university Information Security lab tasks and basic Python practical implementations.It focuses on learning fundamental security concepts and understanding how different cryptographic techniques work through simple programs.

## Topics Covered

- **Encoding & Decoding:** Base64
- **Hashing:** SHA-256, Hash Generation, Avalanche Effect
- **Classical Ciphers:**
  - Caesar Cipher
  - Vigenère Cipher
  - Monoalphabetic Cipher
  - Rail Fence Cipher
  - Columnar Transposition Cipher
- **Modular Arithmetic:** Basic Modular Operations, Modular Inverse
- **Block Cipher Modes:**
  - ECB
  - CBC
  - CFB
  - OFB
  - CTR
- **Image Processing:** Image Loading, Displaying and Basic Manipulation
